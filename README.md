### Secure GitOps Kubernetes Delivery Platform

A cloud-native application delivery platform deployed on AWS with Terraform, kOps, Kubernetes, Docker, Helm, GitHub Actions, and Argo CD.

**Key work:**

- Provisioned AWS networking and Kubernetes infrastructure with Terraform
- Containerised a React frontend and Flask backend
- Implemented GitOps-based delivery with Argo CD
- Added container scanning with Trivy
- Added Kubernetes security controls with Kyverno
- Integrated PostgreSQL, DNS, TLS, monitoring, and secrets
- Diagnosed API routing, authentication, and database connectivity failures

[View project](https://github.com/oparag-dev/capstone-project-novara)

### Event-Driven Microservices on Amazon ECS

A four-service microservices platform deployed on Amazon ECS Fargate with Docker, Terraform, Application Load Balancer, Amazon SQS, ECR, and CloudWatch.

**Key work:**

- Built four independently deployed services
- Implemented asynchronous order events with Amazon SQS
- Configured load balancing and service health checks
- Restricted service traffic through security groups
- Designed separate development and production networking approaches
- Documented cost, security, and architecture trade-offs

[View project](https://github.com/oparag-dev/ecs-event-driven-microservices)

### Multi-Tenant SaaS Backend on AWS

A serverless SaaS backend built with AWS Lambda, API Gateway, Cognito, DynamoDB, IAM, S3, CloudWatch, and Terraform.

**Key work:**

- Implemented Cognito authentication and JWT-based tenant identification
- Designed DynamoDB partitioning around tenant boundaries
- Applied IAM controls for tenant-level access
- Added S3 audit logging and lifecycle policies
- Used Terraform modules and remote state
- Documented tenant isolation risks and production improvements

[View project](https://github.com/oparag-dev/my-saas-project)
